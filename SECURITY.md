# Security policy

## Supported versions

This template ships no service code. Security fixes land on main and flow to
generated repos through template updates. Generated repos own their own
supported versions.

## Report a vulnerability

Use GitHub private vulnerability reporting on this repo (Security tab,
Report a vulnerability). Do not open a public issue for a vulnerability.
Do not include secrets in a report.

## Scope

This policy covers the template files: workflows, hooks, configs, and docs.
It does not cover code in repos generated from this template.
